LS ELECTRIC 저압 소프트스타터(LVSS 시리즈) 선정 웹 페이지.
영업사원이 고객을 만나 모터 조건을 넣으면 카탈로그 선정표에 맞는 모델을 바로 보여 주는 도구다.

## 개발 요청 사항

1. `prototype/index.html`의 화면과 동작을 그대로 살린 정식 웹 앱으로 만든다.
   - 기술 스택은 자유(예: Vite + React/Vue, 또는 정적 HTML 유지). 서버 없이 정적 배포 가능해야 한다.
   - 선정 데이터는 코드에 박지 말고 `data/lvss-selection.json`을 읽어서 쓴다(카탈로그 개정 시 JSON만 교체).
2. PC 브라우저(1280px 이상)와 태블릿(가로/세로) 모두에서 쓸 수 있어야 한다. 폭이 좁으면 왼쪽 패널이 위로 쌓인다.
3. 선정 로직은 아래 "선정 로직" 그대로 구현하고, 단위 테스트를 붙인다(아래 테스트 케이스).

### 왼쪽 패널 — 입력

| 항목 | 입력 방식 | 기본값 | 비고 |
|---|---|---|---|
| 전원 전압 (필수) | 드롭다운 200/220/230/380/400/415/440/460/480 V | 380 | 카탈로그 사용 범위 200~480V |
| 주파수 | 세그먼트 50Hz / 60Hz | 60 | 표시용. 선정에는 영향 없음(50/60Hz 공용) |
| 모터 전류 입력 방식 (필수) | 세그먼트 명판 전류(A) / kW | kW | 방식별 도움말 문구가 바뀜 |
| 값 | 숫자 입력 + 단위 표시 | kW 55 / A 104 | 입력할 때마다 즉시 다시 계산 |
| Trip Class | 세그먼트 10 / 20 / 30 | 10 | 아래 회색 박스에 설명 문구 |
| 상세 조건 › 제어 전원 | 선택 안 함 / DC24V / AC110V / AC220V | 선택 안 함 | |
| 상세 조건 › 주위 온도 | 상관없음 / 40℃ 이하 / 50℃ 이하 | 상관없음 | |
| 상세 조건 › 기동 횟수 | 상관없음 / 시간당 3회 / 시간당 5회 | 상관없음 | |
| 상세 조건 › 효율×역률 | 숫자 | 0.80 | kW 계산에만 사용 |

조건 초기화 버튼은 모든 값을 기본값으로 되돌린다. 조건이 바뀌면 카드 목록의 "한 단계 위" 이동 상태와 "더 보기" 상태도 초기화한다.

### 오른쪽 상단 — 요약 박스 (배경 #1F2A3A)

- 큰 숫자: 선정 기준 전류(A), 반올림 정수. 입력이 비었거나 0이면 `—`.
- 조건 칩: `380 V · 60Hz`, `55 kW (계산)` 또는 `104 A (명판)`, `Trip Class 10`, `주위 -`, `기동 -`, `제어전원 -`, `결선 In Line`.
  값이 정해진 칩은 채워진 파란 칩, 미선택(`-`)은 점선 테두리 칩.
- 계산식 줄(고정폭 글꼴)
  - kW 모드: `I = P / (√3 · V · η·cosφ) = 55kW / (√3 · 380V · 0.80) ≈ 104 A` + `근삿값이에요. 명판 전류를 확인하면 더 정확해요.`
  - A 모드: `명판 정격전류 104 A 그대로 선정에 써요.` + `카탈로그 선정 가이드(In Line 결선) 기준이에요.`

## 선정 로직

1. **기준 전류 I**
   - A 모드: `I = 입력값`
   - kW 모드: `I = kW × 1000 / (√3 × V × (효율×역률))`
2. **후보 찾기**: `rows`를 위에서부터 훑으며 다음을 모두 만족하는 행의 `model[tcXX]`을 모은다.
   - `model[tcXX]`가 null이 아님(XX = 선택한 Trip Class)
   - `motorFlcA ≥ I`
   - 주위 온도 50℃ 선택 시: 그 행의 `dutyGroup`의 `ratedAmbientC ≥ 50` (= 그룹 3 제외, Size 4·5 제외)
   - 기동 횟수 5회 선택 시: `startsPerHour ≥ 5` (= 그룹 1만)
   - 제어 전원 DC24V 선택 시: 모델 번호 307 이상 제외
   - 같은 모델이 두 번 나오면 처음 것만 쓴다.
3. **정렬**: 모델 번호 오름차순(101 → 505). 1순위가 "정격 여유 최소".
4. **카드 값**: 적용 전류 = 그 모델이 나온 행의 `motorFlcA`, 정격 여유 = `(적용 − I) / I × 100` 반올림.
5. **형명 만들기**: 번호 < 307 → `LS-LVSS-{번호}`. 번호 ≥ 307 → AC110V면 `-1`, AC220V면 `-2`, 미선택이면 `-?`.
6. **제어전원 안내 문구**: 307 미만 `제어전원: DC24V / AC110V / AC220V 공용`, 307 이상 `제어전원: -1 = AC110V, -2 = AC220V (DC24V 미지원)`.
7. **프레임 정보**: 모델 번호가 `frames[].from ~ to` 범위에 드는 항목에서 size, amp, bypass, ip, term, dim, amb, page를 가져온다.
